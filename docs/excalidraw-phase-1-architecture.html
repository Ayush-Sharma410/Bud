What Phase 1 added

Bud now has an Excalidraw-first canvas surface. Users can open the canvas with a hotkey, speak to create or edit shapes, ask Bud to propose visual changes as ghost elements, confirm or cancel by voice, undo mistakes, and have sketches autosaved locally.

Embedded canvas

Official Excalidraw React component in a dedicated Electron renderer window.

Voice-first session

Hotkey opens/focuses the canvas and toggles canvas-scoped listening.

Safe operations

Main-process controller gates destructive or ambiguous changes before applying.

Persistence

Dirty-interval autosave writes local .excalidraw sessions plus metadata index.

Important: This has been validated with macOS build/type/test checks. Bud is Windows-targeted, so the real runtime smoke test still needs to happen on Windows before calling it production-ready.

Voice session flow

The canvas is reached through a configurable global hotkey. Press once to open/focus Excalidraw and start the canvas voice session; press again to end listening while keeping the sketch.

1. User presses hotkey

CommandOrControl+Shift+Space; on Windows, Ctrl+Shift+Space.

2. Main process handles shortcut

Global hotkey listener calls canvas session toggle.

3. Canvas window opens/focuses

Window manager creates or focuses the Excalidraw window.

4. Voice session starts

Realtime mute state is managed for canvas-scoped listening.

5. HUD shows state

Canvas HUD shows listening/proposal/saved states.

Press hotkey again → end Bud listening session, keep sketch open

Operation and proposal flow

Phase 1 supports create, edit, review/propose, confirm/cancel, and undo through high-level operations. Large, destructive, or ambiguous requests are not applied silently.

Intent

Voice or chat asks for a drawing/edit/review.

excalidraw_* tool

Tool wraps a controller method.

Controller

Reads scene summary and validates operation.

Safety gate

Immediate apply or requires confirmation.

Renderer update

Approved changes use Excalidraw updateScene.

If review/confirmation is needed

Ghost proposal

Dashed/translucent ghost elements render on the canvas.

Voice confirm/cancel/revise

No primary Approve/Decline buttons; confirmation is spoken or tool-driven.

Commit or clear

Confirm replaces ghosts with real elements; cancel clears ghosts.

Immediate

Small safe creates/updates can apply directly.

Confirmation required

Destructive, bulk, or ambiguous changes go through proposal/confirm.

Unsupported in Phase 1

replaceScene and importScene are not implemented as raw scene operations.

Undo, autosave, and recovery

Phase 1 protects work with a controller-managed snapshot ring and local autosave. Snapshots are internal and ghost-free.

Before Bud mutation

Controller captures internal full-scene snapshot.

SnapshotRing

Bounded by count/age; default 50 / 30 min.

Undo request

Verify scene changed

If native undo fails/no-op, fall back.

Snapshot restore

Restore ghost-free snapshot through official API.

Autosave path

Scene changed

S7 tool surface

The same six tools are registered for Realtime voice and chat/Orchestrator. Each calls an existing controller method; no tool exposes raw scene JSON or internal snapshots.

ToolController methodPurpose
excalidraw_readScenereadScene()Returns compact SceneSummary; excludes ghosts and full scene JSON.
excalidraw_applyOperationapplyOperation(operation)Applies safe operations through the deterministic safety gate.
excalidraw_proposeOperationproposeOperation(operation, options?)Renders ghost proposal elements for visual review.
excalidraw_confirmProposalconfirmProposal(proposalId, optionId?)Commits pending proposal or selected review option.
excalidraw_cancelProposalcancelProposal(proposalId)Clears pending proposal ghosts without applying.
excalidraw_undoundo()Reverts last Bud-applied mutation via native undo or snapshot fallback.

Safety and privacy contract

Compact summaries only

Prompts and tools get SceneSummary, not raw Excalidraw element graphs.

Ghosts are transient

Proposal ghosts are excluded from read summaries, autosaves, and snapshots.

Full snapshots stay internal

Snapshot data is used only by controller-managed undo/autosave paths.

Safety gate is deterministic

Large/destructive/ambiguous operations require confirmation; tools cannot bypass it.
